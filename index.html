💡 Why This Design Succeeds in a Viva:

  • Zero Server Maintenance: No Node.js or Python backend servers to deploy, monitor, or pay for.
  • ₹0 Budget Compliance: Fits 100% within the free Firebase Spark plan limits (50k daily Firestore reads, 20k daily writes).
  • No Cloud Functions Required: Inventory intelligence formulas (Critical threshold, Expiry warnings, Reorder quantities) execute client-side in Vanilla JS, avoiding the paid Blaze plan mandate for Cloud Functions.
  • Real-time Synchronous Updates: Firestore's onSnapshot() listener pushes live inventory updates instantly to all connected browser tabs.

🎓 Top Viva Questions & Answers for Demonstrations

Q1. What is the cloud service model used here?
It uses Backend-as-a-Service (BaaS) / Serverless. Firebase provides database management (Cloud Firestore) and static web hosting (Firebase Hosting) without provisioning virtual machines (IaaS).
Q2. Why is Cloud Firestore called a NoSQL database?
Firestore is a document-oriented NoSQL database. It organizes data into Collections of JSON-like Documents with flexible schemas, rather than relational tables with fixed rows and columns.
Q3. How does the application prevent negative inventory?
During Stock-OUT transactions, client-side validation checks requestedQuantity <= currentQuantity before committing the change to Firestore. If requested amount exceeds current stock, the operation is blocked with an error toast.
Q4. How is ₹0 cost guaranteed on the Firebase Spark Plan?
We strictly use services included in Firebase's perpetual free tier (Firestore & Hosting) and avoided Cloud Functions / external APIs that require upgrading to the pay-as-you-go Blaze plan.
Q5. How does the Reorder Intelligence rule work?
When currentQuantity < minimumStock, the system calculates recommendedOrder = maximumStock - currentQuantity. If stock is at or above maximum target, recommended order evaluates to 0.
Q6. What happens if a chemical is within 30 days of expiry?
The intelligence engine calculates the difference between simulated expiryDate and today. If <= 30 days, it displays an EXPIRING_SOON warning badge and dispatches an alert in the feed without mutating the chemical's inventory stock level balance.
